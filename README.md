Computer Engineering undergraduate at the University of Lagos, focused on **High-Performance Computing (HPC), low-latency data infrastructure, and quantitative systems engineering.**

I build software with a rigorous focus on mechanical sympathy — understanding how code maps directly to hardware execution, cache hierarchies, and memory layouts.
